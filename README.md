# セレンディピティTube

高評価した動画、登録チャンネル、同じ動画にコメントした人の公開情報を手がかりに、自分用の動画棚を作るアプリです。スマートフォン向けの画面で、動画ごとに見つけた理由を表示します。ビルドやサーバー側の処理は不要です。

## Google ログインの設定

1. Google Cloud でプロジェクトを作り、**YouTube Data API v3** を有効にします。
2. Google Auth Platform の OAuth 同意画面で対象を **外部** に設定します。テスト公開中は、テストユーザーに使う Google アカウントを追加します。
3. OAuth クライアント ID を **ウェブ アプリケーション** として作成します。
4. **承認済みの JavaScript 生成元**に `https://kunoyu2.github.io` を追加します。ローカルで使う場合は `http://localhost:8080` も追加します。生成元に `/serendipity-tube/` は含めません。リダイレクト URI は不要です。
5. 発行されたクライアント ID を [config.js](./config.js) の `GOOGLE_CLIENT_ID` に貼り付けます。クライアントシークレットは使いません。

GitHub Pages の公開元にブランチのルートを指定します。ローカルではリポジトリのルートで `python3 -m http.server 8080` を実行し、`http://localhost:8080` を開きます。設定前も「デモデータで試す」で画面を操作できます。デモの動画とサムネイルはサンプルで、再生時はプレビューを表示します。

## 使い方

- Google でログイン後、「更新」を押すと高評価と登録チャンネルを取り込みます。更新は手動です。中止後にもう一度「更新」を押すと、保存済みのデータや API 応答を使って処理を再開します。
- 「発見」に候補、「登録」に登録チャンネルの新着が並びます。「人」からコメント投稿者の公開登録と公開再生リストをたどれます。
- 動画カードをタップするとプレーヤーが開きます。「TV モード」は選んだフィードを順番に再生します。ブラウザーが自動再生を止めた場合は画面の再生ボタンや「音声をオン」を押してください。
- 非表示と視聴履歴は端末の IndexedDB に保存します。設定で履歴を消去したり、視聴済みを再表示したりできます。JSON で保存データを移せます。バックアップには高評価や登録チャンネルなどの情報が含まれます。アクセストークンはセッション内で保持し、書き出しには含めません。
- 対応ブラウザーのメニューからホーム画面に追加できます。サービスワーカーはアプリのファイルだけをキャッシュします。

## API 使用量と制約

- 標準上限はプロジェクトあたり 1 日 10,000 ユニットです。アプリが呼ぶ一覧 API は各リクエストを 1 ユニットとして推定し、米国太平洋時間の日付で集計します。上限エラーの際は更新を止め、取得済みデータを保存します。回数の正確な値は Google Cloud で確認できます。
- 高評価は最大 200 本、登録は最大 500 件です。1 回につき登録チャンネルを最大 40 件ずつ巡回します。コメントは既定で 60 本の動画から各 20 件、投稿者は最大 25 人を調べます。発見候補のチャンネルは最大 240 件を確認します。
- YouTube は動画に高評価した人やチャンネル登録者全員の一覧を公開しません。ログイン中の本人の高評価と登録を読み取り権限で取得します。他人の非公開の登録や高評価は取得できません。登録経由の発見は、コメント投稿者が公開している登録情報に限られます。公開再生リストも発見の手がかりにします。
- 180 秒以下、タイトル・説明・タグに `shorts` を含む動画、配信中・配信予定、取得時に利用不可の動画を除外します。Data API には Shorts 専用の判定フィールドがないため、判定には取得できる時間とメタデータを使います。埋め込み側の表示は YouTube の仕様に従い、`rel=0` の関連動画も YouTube が制御します。
- 地域や年齢制限などで再生できない動画があります。TV モードでは再生エラーの動画をスキップします。
