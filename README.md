# はてブ動画

はてなブックマークで話題になったYouTube動画を探せる静的サイトです。ブックマーク数や初回ブックマーク日で並べ替えたり、ブクマコメントを読んだり、現在の絞り込み結果をTVモードで連続再生したりできます。ログインとAPIキーは不要です。

## ローカルで動かす

Node.js 20以上で動作し、npm依存関係はありません。収集にはインターネット接続が必要です。

```sh
node scripts/collect.mjs --mode daily
python3 -m http.server 8080
```

ブラウザーで `http://localhost:8080/` を開きます。表示と絞り込みには同梱のJSONを使います。公開データを初めて収集するまでは一覧は空です。オフラインでの検証は次のコマンドで行えます。

```sh
node --test
find . -type f \( -name '*.js' -o -name '*.mjs' \) -not -path './.git/*' -exec node --check {} \;
```

## 収集と更新

- 日次収集では、はてなの `/entrylist?mode=rss&sort=hot&threshold=3` を使い、YouTubeの通常URLと短縮URLの両方を動画IDの先頭1文字（各64通り）で分割します。両ドメインの `/site/…/` と `/hotentry/all.rss` も確認します。
- 動画IDで統合し、URL違いでは最大のはてブ数と最も古い初回ブックマーク日を採用します。直近60日以内に初回ブックマークされた動画と、最終件数確認から30日以上経った動画は `bookmark.hatenaapis.com/count/entries` で確認します。正規URLを使い、記録済みの別URLがあれば併せて最大50 URLずつ問い合わせます。
- 新着候補をはてブ数順にYouTubeの `/oembed` で確認します。HTTP 400、401、403、404は恒久除外として記録します。`/shorts/<ID>` は手動リダイレクトで確認し、200は恒久除外、同じIDの `/watch` への301、302、303は通常動画として扱います。判定できなかった候補は保留します。ShortsやライブのURL、再生リストだけのURLはRSSの取り込み対象外です。
- はてブ数10件以上の動画は `/entry/jsonlite/` から最大3件のコメントを選びます。重複やURLだけの投稿を除き、10〜140文字の候補を使います。同じ動画のコメントは30日以上空けて確認します。
- リクエストは逐次実行し、はてなのRSS・コメント用ホストでは1秒以上、その他では0.5秒以上の間隔を空けます。429、5xxや一時的な通信失敗には待ち時間を延ばして最大3回再試行し、失敗が続けば進捗を保存して終了します。すべての収集リクエストのUser-Agentは `serendipity-tube/1.0 (+https://github.com/kunoyu2/serendipity-tube)` です。

## 過去分を集める

```sh
node scripts/collect.mjs --mode seed --max-requests 4000 --time-budget-min 300
```

初回に新着RSSも確認し、過去分は `sort=count&threshold=5` で収集します。RSSに上限の30件が返った場合は先頭文字を追加し、最大3文字まで分割します。同じデータディレクトリで再実行すると完了済みの取得を飛ばします。`--data-dir` の既定値は `data` です。`--max-enrich` と `--max-comments` の既定値はそれぞれ800件と300件です。取得上限は再試行にも適用されます。公開済みの履歴と処理待ち候補は次回に引き継がれます。

## データファイル

| ファイル | 内容 |
| --- | --- |
| `data/videos.json` | 公開動画。はてブ数の降順。`id` は動画ID、`t` は題名、`c` と `cu` はチャンネル名とURL、`n` は件数、`d` は初回ブックマーク日、`u` は件数の確認日。`s:1` はコメントあり。 |
| `data/comments/<先頭2文字の小文字>.json` | 動画IDごとの選抜コメント。`u` ははてなID、`c` は本文、`d` は投稿日時。 |
| `data/meta.json` | 生成日時、公開件数、日付範囲、形式バージョン、日次収集日、過去分の進捗。 |
| `data/pending.json` | 公開可否の確認待ち候補。 |
| `data/excluded.json` | 恒久除外した動画IDと理由。 |
| `data/crawl-state.json` | 完了した分割取得と各処理の再開情報。 |

## GitHub Pages

リポジトリの **Settings → Pages → Build and deployment** で **GitHub Actions** を選びます。ワークフローは毎日18:00 UTC（翌03:00 JST）に日次収集し、`data/` の変更をボットでコミットして同じ実行で公開します。手動実行では `daily` または `seed` と `max_requests` を指定できます。収集は約5時間で区切り、途中までの結果も保存します。通常の `main` へのプッシュでは公開のみを実行します。

## プライバシーと制約

非表示、視聴履歴、絞り込み設定はブラウザー内に保持し、サイトから外部へ送信しません。サムネイルと再生はYouTubeに接続し、はてブのリンクを開くとはてなに移動します。設定画面で非表示と視聴履歴をJSONとして移行できます。

RSSは1クエリ30件まででページ送りがなく、分割しても収集範囲は一部に限られます。はてブ数は後から変動し、条件に合うコメントがないこともあります。oEmbedとShorts判定には変更されうる応答仕様があり、地域制限や公開設定により再生できない動画もあります。YouTubeの埋め込みプレーヤー内の表示はYouTube側の仕様に依存します。

着想はAndrej KarpathyのHackerTube。動画の発見とコメントの出典は、はてなブックマークです。
